# Daily Log 生成プロンプト

前日の会話から「思考の流れ」を抽出してください。

## 対象範囲

- 「前日の会話」とは、前日の日付に実際に行われた会話のみを指す。
- 前日より前の日の会話内容は、原則として抽出対象に含めない。
- 過去の会話に関連する話題が前日に出てきても、過去の会話そのものを遡って補完しない。
- 前日の会話の中で「以前話した○○」などと言及された場合も、その過去の内容を詳細に再構成しない。
- 前日の会話に実際に現れていない思考・出来事・アイデアを、文脈から推測して追加しない。
- 前日の会話だけでは思考の流れが十分につながらない場合は、無理に補完せず、その日に実際に話された範囲でまとめる。

## 出力ルール

以下のMarkdown形式で出力してください。

### 重要：そのまま.mdファイルに貼り付けられる形にする

- **回答全体を、外側の4つのバッククォートによるコードブロック1個だけで囲む。**
- 回答の最初を ` ````markdown ` で開始し、最後を ` ```` ` で終了する。
- 外側のコードブロック以外には、説明文・前置き・後置きを一切付けない。
- 外側のコードブロックの中身は、VSCodeなどにそのまま貼り付ければMarkdownファイルとして成立する完全なMarkdownにする。
- 思考の流れを示す内部のコードブロックには、通常どおり3つのバッククォートを使用する。
- **内部に3つのバッククォートが含まれるため、外側は必ず4つのバッククォートを使用する。**
- コードブロック内にはidを付与しない。
- Markdownの見出し、箇条書き、水平線、内部コードブロックなどの構造を省略・平坦化しない。
- 「### 気づき」などの見出しも必ずMarkdownの見出しとして保持する。
- 内容を省略せず、会話中の思考の流れをできるだけ残す。

- ...

```text
