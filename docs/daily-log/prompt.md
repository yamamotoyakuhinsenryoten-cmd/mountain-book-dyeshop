# Daily Log 生成プロンプト

前日の会話から「思考の流れ」を抽出してください。

## 出力ルール

以下のMarkdown形式で出力してください。

# YYYY-MM-DD（曜日）

## トピック

- トピック1
- トピック2
- ...

---

## 思考の流れ

### 1. タイトル

```text
思考の流れ
↓
...
```

### 気づき

- 気づき
- 気づき

---

（必要な数だけ続ける）

---

## 今日生まれたアイデア

- アイデア
- アイデア

---

## 今日の一番大きな思考の変化

```text
思考の流れ
↓
...
```

## ポリシー

- 出来事ではなく「思考の変化」を優先する
- 話題ごとではなく、思考が変化した単位でまとめる
- なぜその考えに至ったかが分かるようにする
- 気づきは抽象化して残す
- 会話の流れをできるだけ残す
- Markdownでそのまま保存できる形で出力する
- コードブロック内にはidを付与しない
- 日付は会話の日付を使用する
