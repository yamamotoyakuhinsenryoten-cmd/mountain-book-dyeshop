# 202608 振り返り

## コーヒー

### やったこと

- 手鍋焙煎をブラジルで10回くらい実施
- 焙煎時の火力の感覚が少しつかめてきた
- ブラジル以外の豆にも取り組み始め、ニカラグアを購入して焙煎
- 水曜を基本にコーヒーを飲みに行き、ゲイシャなどスペシャリティコーヒーも飲んだ
- アイスコーヒーも何度か淹れた

### 感想

- 思っていたより火力が強く、ガスコンロからシューっと音が聞こえるくらいだった
- ニカラグアはガス切れで中煎りくらいになったが、酸味と苦味がありバランスよく感じた
- ゲイシャなど、今まで知らなかった味に出会えておもしろい。コーヒーの幅が広がる感じがする
- 自分はそこまでアイスコーヒーが好きではなく、ホットのほうがコーヒーを楽しめる気がする
- 最近はブレンドも気になる

### これからやりたいこと

- ブラジルを一番深いところまで焙煎してみる
- ニカラグアをもう少し深煎りにして、2ハゼ後1分くらいまでやってみる
- ブラジルとニカラグアの味の違いを比べてみる
- ブレンドも試してみる
